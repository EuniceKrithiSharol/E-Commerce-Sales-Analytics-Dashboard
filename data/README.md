# Dataset Information

This project uses a simulated e-commerce dataset generated using Python.

The dataset contains information related to:

- Order ID
- Order Date
- Product Category
- Region
- Product Name
- Sales
- Quantity
- Profit

## Dataset Generation

The dataset is generated dynamically inside the Streamlit application using NumPy and Pandas.

This approach allows the dashboard to demonstrate the complete analytics workflow without requiring a large external dataset.

## Future Improvements

Future versions of this project can integrate real-world e-commerce datasets from public data sources.
